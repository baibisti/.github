Organization-level default health files, workflows, issue templates, and GitHub profile configuration for the Bisti organization (`baibisti`).

## Structure

- `profile/`: GitHub organization profile document and verified brand assets (`README.md`, `assets/`, `i18n/`).
- `verify_profile.py`: Automated profile asset, integrity, and motion-preference verification script.
- `DEPLOYMENT.md`: Manual and CI handoff instructions for organization profile deployment.

## Verification

```bash
python3 verify_profile.py
```
